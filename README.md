# 🤖 AI Automation with n8n

Portfolio of AI-powered automation workflows built with **n8n**, **Google Gemini**, and cloud integrations.

## 🚀 About

This repository contains automation workflows developed as part of my studies in AI Agents and workflow automation.

The goal of these projects is to practice the integration of AI models with cloud services, creating intelligent workflows capable of automating real-world business processes.
